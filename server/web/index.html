                    Cookies de YouTube

                    YouTube suele bloquear descargas desde el servidor. Cargue un cookies.txt (formato Netscape) exportado de un navegador con sesión de YouTube iniciada. En Safari (Mac): yt-dlp --cookies-from-browser safari --cookies cookies.txt --skip-download https://www.youtube.com (requiere brew install yt-dlp y «Acceso total al disco» para la Terminal). En Chrome o Firefox, la extensión «Get cookies.txt LOCALLY».
